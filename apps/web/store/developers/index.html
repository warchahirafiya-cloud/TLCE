SUBMISSION REQUIREMENTS

ملف تقديم مكتمل

جهّز بيانات المنتج قبل فتح بوابة التقديم. لا ترسل كلمات مرور أو مفاتيح خاصة أو عبارات استرداد أو وثائق شخصية عبر مستودع عام.

  1. اسم المنتج ووصف دقيق وتصنيف ومنصة مستهدفة.
  2. اسم المطوّر والجهة المالكة وإثبات حق التوزيع.
  3. رابط المصدر أو صفحة المنتج الرسمية وسياسة الخصوصية.
  4. الإصدار وسجل التغييرات والدعم وطريقة الإبلاغ عن الثغرات.
  5. الأذونات المطلوبة وسبب كل إذن والبيانات التي تتم معالجتها.
  6. التراخيص ومكونات الطرف الثالث ومصادرها.

لا توجد حالياً قناة تقديم مفعّلة. هذه المتطلبات مواصفة تحضيرية وليست نموذج إرسال.

REVIEW INDEPENDENCE

المطوّر لا يراجع منتجه.

الاعتماد قرار منفصل عن مقدم الطلب. يجب أن تسجل كل مراجعة هوية المراجع والقرار والأسباب ومرجع الإصدار، وأن تكون قرارات النشر قابلة للتدقيق والتراجع.

  • لا اعتماد ذاتي.
  • لا نشر تلقائي بعد التقديم.
  • لا مفاتيح خاصة داخل GitHub أو الموقع.
  • إمكانية تعليق المنتج أو سحبه عند ظهور خطر.
  • سجل مراجعات وإصدارات قابل للتدقيق.
